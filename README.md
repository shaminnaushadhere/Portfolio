# Project Sentinel

Interactive cybersecurity portfolio for Shamin Naushad, built with React, Vite, Tailwind CSS, Framer Motion, Three.js, Lucide React, and React Router.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- The app is standalone and does not include authentication, protected routes, or external AI/API calls.
- The AI analyst and terminal are local simulations using predefined responses.
- Put Shamin's resume at `public/resume.pdf` so the resume vault download works.
